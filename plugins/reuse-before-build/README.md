# Reuse Before Build

GitHub-first prior-art review for Codex.

Use `$reuse-before-build` before substantial software development to compare existing projects against the requested capability and choose:

- `USE DIRECTLY`
- `FORK / COMPOSE`
- `BORROW PATTERNS`
- `BUILD FRESH`

The skill independently verifies source, maintenance, license, security, deployment, and exit cost. Implementation remains blocked until the user explicitly approves the recommendation.
